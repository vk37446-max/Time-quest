# Time Quest

A Python arcade game: collect glowing time orbs, dodge moving hazards, and survive for 100 seconds.

## Requirements

- 64-bit Python 3.12
- Pygame 2.6.1

## Install and play on Windows

Open PowerShell in the folder containing the game files, then run:

```powershell
py -3.12 -m pip install --upgrade pip
py -3.12 -m pip install -r requirements.txt
py -3.12 time_quest.py
